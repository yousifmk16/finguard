# Node Environment Runbook

This runbook documents frontend Node.js setup for local development.

## Version

- Node.js `20` (see `frontend/.nvmrc`)

## Setup

```bash
cd frontend
npm install
```

## Verify

```bash
cd frontend
npm run lint
npm test
```

## Notes

- Current frontend scripts are placeholders for Sprint 0.
- Real app dependencies/scripts will replace these in implementation sprints.
