2) What the CI workflow does
- Triggers on push and pull_request for `main` and `develop`.
- Runs two jobs in parallel:
  - `backend`: Python setup, lint, and test placeholders.
  - `frontend`: Node setup, lint, and test placeholders.

3) Placeholder-safe behavior
- Backend:
  - Installs `backend/requirements-dev.txt` if present; otherwise installs `ruff` and `pytest`.
  - Runs `ruff` if `backend/ruff.toml` exists.
  - Runs tests only if files exist under `backend/tests`.
- Frontend:
  - Installs dependencies only if `frontend/package.json` exists.
  - Runs lint only if a `lint` script exists.
  - Runs tests only if a `test` script exists.
