2) What Was Implemented
- bcrypt-hashed credentials and HS256 JWT encode/decode in `app/core/security.py`,
  configured via JWT_SECRET / JWT_ALGORITHM / JWT_EXPIRE_MINUTES env vars. A dev
  fallback secret keeps unit tests runnable; production deploys must override it.
- `users` table (DB-04 sibling) carrying email, hashed_password, role, is_active,
  created_at, with a unique index on lower(email).
- `POST /api/v1/auth/login` validates credentials and returns a bearer token plus
  ttl and granted role.
- `get_current_user` FastAPI dependency resolves the Authorization header into a
  `CurrentUser` (user_id, email, role). Rejects missing/wrong-scheme headers,
  invalid signatures, expired tokens, non-UUID `sub` claims, and tokens whose
  user is missing or inactive. SEC-02 will consume the role; this task does not
  enforce per-endpoint RBAC.
- All existing API endpoints stay unauthenticated for now (their TODO AUTH-01
  comments remain), since wiring them is the scope of SEC-03.
