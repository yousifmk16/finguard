# Task Deliverable Records

This directory stores per-task deliverable records (SKL, REQ, ARC, DAT, ING, DB, etc.).

Naming convention:

- `<TASK-ID>_short_title.txt`
- Example: `SKL-01_finguard_Repository_and_Branch_Rules.txt`

Process rule:

- For every completed task, add/update a matching record file here.
- Include: task id, owner, status, evidence files, acceptance checklist.
- Link major sprint summaries from `docs/sprint/deliverables/index.md`.
